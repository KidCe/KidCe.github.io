# 2026 Racing Setup

My main race quad is built for a direct, consistent feel and the low-latency HDZero video system.

## Components

| Component | Part |
| --- | --- |
| Frame | Drippuh by SanderPuh |
| Motors | T-Hobby Velox V3 2050KV / T-Hobby F50 under testing |
| Flight controller | HDZero Halo FC, ICM42866P gyro |
| ESC | HDZero Halo ESC, AM32 |
| Video system | HDZero |
| Antenna | Rush Cherry Y-Type |
| Dry weight | 262–285 g, depending on motors and front brace |

## Motor testing

I am currently testing the T-Hobby F50 motors and considering switching the entire racing setup to them. Compared with the Velox V3, the F50 configuration saves 17 g with the same frame configuration.

## Weight comparison

| Motors | Frame configuration | Dry weight |
| --- | --- | ---: |
| T-Hobby Velox V3 2050KV | One front brace | 285 g |
| T-Hobby Velox V3 2050KV | No front brace | 279 g |
| T-Hobby F50 | One front brace | 268 g |
| T-Hobby F50 | No front brace | 262 g |
