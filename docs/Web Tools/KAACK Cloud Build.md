# KAACK Cloud Build

KAACK Cloud Build is an independent browser-based firmware builder for KAACK Community and official Betaflight release lines.

Choose a firmware line, version, flight-controller target, and supported build options. The service dispatches a validated GitHub Actions build and provides a firmware artifact together with provenance information. Official Betaflight and KAACK Community releases remain separate in the catalog.

Use it when you need a reproducible custom firmware build. Always verify the target, source version, manifest, and checksum, then perform a props-off bench test before flight. A successful build does not prove hardware compatibility, and the project is not affiliated with or supported by Betaflight.
