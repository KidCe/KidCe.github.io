
# Web Tools

Browser-based utilities for FPV setup, diagnostics, and workshop tasks. These tools run directly in a supported browser and link to their source repositories where available.

## Available tools

### [Betaflight RX Monitor](Betaflight RX Monitor.md)

Connect to a Betaflight flight controller over USB, monitor receiver status, and receive configurable audio alerts for receiver and USB connection problems.

- [Open the tool](https://kidce.github.io/BetaflightStatusReadout/)
- [View the source code](https://github.com/KidCe/BetaflightStatusReadout)

### [KAACK Cloud Build](KAACK Cloud Build.md)

Build and download selected KAACK Community or official Betaflight firmware targets through a browser-based, GitHub Actions-backed workflow.

- [Open the tool](https://kidce.github.io/KAACKCloudBuild/)
- [View the source code](https://github.com/KidCe/KAACKCloudBuild)

### [KidCe Configurator](KidCe Configurator.md)

An independent, monochrome Betaflight Configurator build based on the pinned 2025.12.2 source line, with browser access to supported flight-controller hardware.

- [Open the tool](https://kidce.github.io/KidCe-Configurator/)
- [View the source code](https://github.com/KidCe/KidCe-Configurator)

### [RatesManager](RatesManager.md)

Manage Betaflight rate profiles from an EdgeTX radio: keep local profiles, synchronize slots P1–P3 over CRSF, and use guarded temporary or persistent writes.

- [View the project and downloads](https://github.com/KidCe/RatesManager)

## Publishing scope

Pages in this folder are intended for publication to the FPV Wiki through the FPW Wiki Publisher. Internal development notes, unfinished experiments, credentials, private paths, and unreviewed drafts do not belong here.
