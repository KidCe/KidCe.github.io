## Source precedence

1. Fresh physical target observation.
2. Read-only artifact from that target.
3. Exact repository revision recorded above.
4. Dated community report.
5. Inference.

Repository pages can change. Keep the inspection date beside any new fast status and update this registry before changing a canonical guide.
