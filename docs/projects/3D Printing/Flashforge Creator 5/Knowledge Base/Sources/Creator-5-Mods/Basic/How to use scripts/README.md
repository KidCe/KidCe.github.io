# How to use autoinstall scripts
Tutorial by Cart

## Requirements:
Root, SCP file manager

### Tutorial:

1. Open your SCP file manager of choice and log in
2. Transfer the script you would like to use to your default directory
3. Log into your printer over SSH
4. Run `chmod +xwr (nameofscript).sh`
5. Run `./(nameofscript).sh`
