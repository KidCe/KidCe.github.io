
# Flashforge Creator 5 Mods

## For future Claude

This folder contains privately collected and manually pasted Discord information about Flashforge Creator 5 modifications. Treat the notes as unverified source material. Do not assume that instructions are safe or current without checking the relevant scripts, firmware version, and printer model.

- [How to Install](How to Install.md) — Root access and the safer startup-script installation method.
- [Important Notes](Important Notes.md) — Update, bricking, persistence, and security warnings.

- [Discord Mods Dump](Discord Mods Dump.md) — Temporary inbox for new copied Discord text blocks.

## Source handling

The notes were distilled from copied Discord messages. Speaker names and dates are retained where they add context. Links point to repositories mentioned in the source dump; no independent verification was performed here.

## Repository verification

The linked repositories were checked on 2026-08-24. The comparison is recorded in [Repository Check](Repository Check.md). Current repository instructions take precedence over older copied Discord instructions.
